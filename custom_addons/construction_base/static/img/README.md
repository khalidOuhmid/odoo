# Images pour les contrats

Pour que le contrat de sous-traitance s'affiche correctement, vous devez placer les images suivantes dans ce dossier :

1. **blg_logo.png** - Logo BLG Groupe (dimensions recommandées : 200x80px)
2. **blg_signature.png** - Signature BLG avec cachet (dimensions recommandées : 200x100px)

Ces images sont référencées dans le template de contrat `subcontractor_contract_template.xml`.

Si vous n'avez pas ces images, vous pouvez temporairement les remplacer par un logo par défaut d'Odoo ou commenter les balises `<img>` dans le template.
