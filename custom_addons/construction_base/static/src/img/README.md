# Images de branding

Conservez ici les visuels partagés entre les rapports (logo, signatures, etc.) :

1. **blg_logo.png** - Logo BLG Groupe (dimensions recommandées : 200x80px)
2. **blg_signature.png** - Signature BLG avec cachet (dimensions recommandées : 200x100px)

Les rapports utilisent ces fichiers si disponibles. À défaut, Odoo utilisera automatiquement le logo configuré sur la société.
